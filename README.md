# 우리집 인테리어 모델러

아파트 도면을 바탕으로 만든 브라우저용 3D 인테리어 모델링 도구입니다. 빌드 과정 없이 정적 파일로 동작하며, Three.js는 CDN(jsDelivr)에서 불러옵니다.

## 실행

ES 모듈을 쓰기 때문에 파일을 직접 열지 말고 로컬 서버로 띄워 주세요.

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```

## 기능

- **3D / 평면도 / 눈높이** 시점 전환 (눈높이: 드래그로 둘러보기, W A S D·방향키로 이동)
- 공간별 이름·면적(㎡, 평) 라벨과 목록, 목록 클릭 시 해당 공간으로 이동
- 벽 낮춰 보기(단면), 철거된 벽 위치 표시
- 가구 추가·선택·드래그 이동(5cm 스냅)·회전(`R`, 90° 버튼)·크기 수정·복제·삭제
- 가구 배치는 브라우저에 자동 저장, JSON으로 복사/불러오기

## 현재 도면 반영 사항

- 빨간 박스로 표시된 방은 **펜트리**로 모델링 (수납 선반, 김치냉장고 배치)
- X 표시된 두 벽(구 방의 북측·동측 벽)은 **철거된 상태**로 모델링. 원래 벽 위치는 "철거된 벽 위치 표시"로 확인 가능
- 치수는 도면 이미지 비율로 추정한 값입니다(전용 약 125㎡). 실측 치수가 있으면 `src/plan.js`만 수정하면 됩니다.

## 파일 구조

| 파일 | 내용 |
| --- | --- |
| `src/plan.js` | 벽·문·창·공간·초기 가구 배치 데이터 (단위 m) |
| `src/builder.js` | 벽(개구부 포함)·바닥·철거벽 3D 생성 |
| `src/furniture.js` | 가구 카탈로그와 3D 모델 |
| `src/main.js` | 씬, 카메라, 선택/드래그, 사이드바 UI |

## 바닥재·벽지·가구 바꾸기 (v2)

### AI 요청 탭
참고 이미지(여러 장 가능)를 끌어다 놓고 "거실 바닥을 사진 같은 헤링본으로", "사진 속 소파로 바꿔줘"처럼 적으면 Claude가 변경안을 만들어 바로 적용합니다.
- 3D 화면에서 공간(바닥)이나 가구를 누르면 요청 대상으로 잡힙니다.
- 한 번의 요청은 **되돌리기** 한 번으로 전부 취소됩니다.
- 모양이 특별한 가구는 기본 도형(상자·원기둥·구)을 조합한 **맞춤 모델**로 만들어집니다.
- 참고 이미지는 **이미지 첨부** 버튼, 끌어다 놓기, 붙여넣기(Ctrl+V)로 넣습니다. 사진을 누르면 크게 보면서 원하는 부분의 색을 스포이트로 찍을 수 있습니다.
- 사진은 JPEG로 정리해 Claude에게 보내고, 페이지가 뽑은 주요 색과 찍은 색도 함께 보냅니다. 사진을 직접 보낼 수 없는 화면에서는 색 정보만 보냅니다.
- claude.ai 아티팩트로 열었을 때 동작합니다(`sample` 기능). 로컬에서는 버튼이 비활성화되고, 대신 Claude Code 대화에 요청하면 됩니다.

### 마감재 탭
공간별 바닥재·벽지를 패턴(마루·헤링본·타일·서브웨이·대리석·테라조·줄무늬·체크·도트 등), 주색/보조색, 단위 크기, 광택으로 직접 조정합니다. 벽은 방마다 안쪽 면이 따로 칠해집니다.

### 저장
디자인(`{ surfaces, furniture }`)은 브라우저에 자동 저장되고, claude.ai에서 열면 아티팩트 DB(`design/current`)에도 저장되어 Claude 대화에서 읽고 고칠 수 있습니다.

| 파일 | 내용 |
| --- | --- |
| `src/materials.js` | 마감재 스펙, 패턴 텍스처 생성 |
| `src/ai.js` | Claude 요청문 생성, 응답(액션) 검증 |
